# Result tables

Every table in this directory is written by one script and by only one script. The `R`, `N` and `X` prefixes are work-package
labels from the order the analyses were done; they carry no meaning beyond grouping, and
the part of the filename after the prefix says what the table holds.

The directory is empty in a fresh clone. Running the scripts fills it.
